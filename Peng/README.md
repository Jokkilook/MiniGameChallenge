# PENG! — 공기폭발 협동 질주 (프로토타입)

WebGL 3D FPS(외부 라이브러리 없음). PoofGun(공기폭발 총)으로 발밑을 쏴 **로켓점프**로 협곡을 넘어 결승선까지. 솔로 또는 여러 명 협동.

## 혼자 플레이 (오프라인)

`index.html`을 브라우저로 그냥 열면 됩니다. 외부 라이브러리·인터넷 불필요. 멀티는 자동으로 비활성(솔로)로 폴백됩니다.

## 멀티플레이 (세션 코드로 함께)

의존성 0 Node 서버가 포함되어 있습니다. `npm install` 필요 없음.

```bash
node server.js
```

접속: <http://localhost:8090/>

> ⚠️ **반드시 위 주소로 여세요.** `index.html` 파일을 더블클릭해서 열거나(`file://`),
> 다른 정적 서버(예: `python -m http.server`) 주소로 열면 그쪽에는 멀티 서버가 없어
> "멀티 서버에 연결할 수 없습니다"가 뜹니다. 메인 메뉴 하단에 현재 상태
> (🟢 준비됨 / ⚠️ 안내)가 표시되니 확인하고 시작하세요.

### 함께 하는 순서

1. **호스트**: 메인 메뉴에서 **방 만들기** → 6자리 **세션 코드**가 나오고 대기방으로 이동
2. 그 코드를 친구에게 알려줍니다 (대기방의 *코드 복사* 사용)
3. **친구**: 같은 주소로 접속 → **방 참가하기** → 코드 입력 → 대기방 합류
4. 대기방에 2명 이상이 되면 호스트의 **게임 시작** 버튼이 활성화 → 누르면 **전원 동시 시작**

- 포트 변경: `PORT=3000 node server.js`
- 친구가 **다른 PC**에서 들어오려면 같은 공유기라면 호스트 PC의 내부 IP로 접속(`http://192.168.x.x:8090/`),
  인터넷 너머라면 8090 포트 개방 또는 터널(ngrok 등)이 필요합니다.
- 없는 코드를 입력하면 "방을 찾을 수 없어요"로 거부됩니다(빈 방이 생기지 않음).

### 동작 방식 (릴레이 넷코드)

각 클라이언트가 자기 물리를 로컬에서 돌리고, 자기 상태(위치·시점·반동)와 발사한 **폭발(blast)** 만 서버로 보냅니다. 서버는 같은 방의 다른 사람에게 그대로 중계합니다.

- 상대는 **청록 캡슐 + 총**으로 렌더됩니다.
- **핵심 협동**: 팀원이 쏜 펑건 폭발 반경 안에 있으면 **날아갑니다** — 서로 밀어서 협곡을 넘겨주세요!
