# SFX — 파일 효과음

여기에 파일을 떨어뜨리면 게임이 씁니다. 이름이 정확해야 합니다(전부 소문자, 공백 없음
— 배포 대상인 리눅스는 대소문자를 구분합니다).

| 파일 이름 | 언제 | 없으면 |
|---|---|---|
| `shoot.mp3` | 펑건 발사 | 합성음으로 떨어짐 |
| `hit.ogg` | 폭발에 밀렸을 때(피격) | 무음 |
| `hitrev.ogg` | **끌어당기는** 폭발에 맞았을 때(리버스캡슐) | 무음 |
| `pickup.ogg` | 아이템 패드를 밟았을 때 | 합성음으로 떨어짐 |

`.mp3` 가 없으면 `.ogg` 를 찾고, 둘 다 없으면 콘솔에 한 줄 남기고 넘어갑니다.

`hit` 과 `hitrev` 가 갈려 있는 이유는 대처가 정반대이기 때문입니다. 밀리는 것과 끌려오는
것은 가장자리 근처에서 사는 길이 서로 반대라, 화면을 안 보고도 어느 쪽인지 알아야 합니다.
**두 소리는 확실히 달라야 합니다** — 비슷하면 갈라 놓은 의미가 없습니다.

## 거리 감쇠

이 소리들은 전부 **월드의 한 지점에서** 납니다(언리얼의 attenuation 과 같은 것을
WebAudio `PannerNode` 로). 듣는 자리는 카메라입니다.

- 모델 `inverse`(1/r) · `SFX_REF` 9m 안쪽은 원래 크기 · `SFX_MAX` 80m 밖은 더 안 줄어듦
- 값은 `index.html` 의 `SFX_REF` · `SFX_MAX` · `SFX_ROLL` 셋입니다

그래서 **소리를 만들 때 거리감을 미리 넣지 마세요.** 리버브를 잔뜩 먹여 두면 코앞에서
터져도 멀리서 나는 것처럼 들리고, 감쇠가 그 위에 또 걸립니다. 가까이서 들은 소리를
그대로 두면 됩니다.

## 여기 있는 것과 uiassets.js 에 있는 것의 차이

버튼 소리(hover·click·swap)는 `uiassets.js` 에 base64 로 **구워져** 있습니다. 그쪽은
`index.html` 을 더블클릭해서 여는 오프라인 플레이에서도 나야 하는 소리라 그렇습니다.

여기 있는 것은 파일로 받습니다(BGM 과 같은 방식). 소리 하나 바꾸는 데 굽는 절차를
거치지 않아도 되지만, `file://` 로 열면 fetch 가 막혀 안 납니다 — 그때는 합성음으로
떨어지므로 게임은 그대로 돌아갑니다.

## 발사음을 고를 때

- **짧아야 합니다.** 발사 간격이 0.12초(`_fireCd`)라 연사하면 겹칩니다. 긴 꼬리가 있으면
  `index.html` 의 `SHOOT_CUT`(기본 0.4초)이 잘라 내는데, 애초에 짧은 소리가 낫습니다.
- **때리는 앞부분이 분명해야 합니다.** 잘려 나가는 건 꼬리 쪽입니다.
- 크기는 효과음 버스를 거치므로 설정의 '효과음' 슬라이더에 따라갑니다. 다른 소리와
  묶어 들었을 때 튀지 않을 정도로 정규화해 두세요.
