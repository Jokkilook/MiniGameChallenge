# 빛 구슬 · Lumen Line

선을 **그려** 길을 만들고, **빛 구슬**을 굴려 등불에 넣는 물리 그리기 퍼즐.
잉크는 한정, 붉은 가시는 피하라. 빛/그림자 세계관의 세 번째 게임(C).

> 2026 미니게임 메이커스 챌린지 / 경기게임오디션 출품 후보 (기획 C).

## 플레이 방법

- `C/index.html` 을 브라우저에서 열면 바로 실행. (외부 물리엔진 없음, 단일 파일)
- **드래그**로 그림자 잉크 선을 그림 → **Space/드롭** 으로 빛 구슬을 떨어뜨림
- **Z** 되돌리기 · **R** 다시. 구슬이 **등불(초록 원)** 에 닿으면 클리어.
- 잉크(하단 게이지)는 한정 → 최소한의 선으로 영리하게.

## 왜 다른가 (A·B와의 차이)

| | 입력 | 장르 | 핵심 재미 |
|---|---|---|---|
| A 움브라 | 격자 이동 | 퍼즐 | 그림자로 길찾기 |
| B 서바이벌 | 실시간 이동 | 아케이드 | 빛 회피 생존 |
| **C 빛 구슬** | **자유 그리기** | **물리 퍼즐** | **선을 그려 굴리기** |

→ 세 게임이 하나의 세계관(빛/그림자)인데 **입력·장르·재미가 전부 다름.**

## 레벨 (4)

1. **첫 낙하** — 비탈을 그려 굴리기 (기본)
2. **기둥 너머** — 벽을 넘어가는 길
3. **가시 구덩이** — 가시 위로 다리 놓기
4. **높은 벽** — 벽을 넘고 가시를 건너기 (종합)

## 기술 메모 / 검증

- 순수 HTML5 + Canvas 2D. **원 vs 선분 충돌**을 직접 구현(라이브러리 0).
- 물리: 중력 + 서브스텝 적분, 접촉마다 위치 보정 + 속도 반응. **부드러운 굴림**을 위해
  약한 충격은 비탄성(무반동) 처리하고 강한 충돌만 반발(restitution) 적용 → 미세 튕김/정지 버그 제거.
- **헤드리스 시뮬레이션으로 4개 레벨 전부 "잉크 예산 내 풀이 가능" 검증**, 콘솔 에러 0.

## 개발 중 잡은 버그

- 평평한 시작 발판이 구슬을 가두던 것 → 공중 낙하로 변경(그린 선이 실제로 의미 있게).
- 마찰·반발이 서브스텝마다 누적되어 구슬이 비탈 중간에 서던 것 → 접촉당 1회 처리 + 저마찰로 수정.
- 벽 모서리를 스치며 멈추던 것 → 레벨 여유 조정.
