# 움브라 · Umbra

빛은 너를 얼어붙게 하고, 오직 **그림자**만이 너를 움직이게 한다.
상자를 밀어 그림자를 만들고, 출구로 향하는 그림자 퍼즐.

> 2026 미니게임 메이커스 챌린지 출품작 (개발 중)

## 플레이 방법

- 저장소의 `game/index.html` 을 브라우저에서 열면 바로 실행됩니다. (별도 서버·빌드 불필요)
- 조작: **← ↑ ↓ →** 또는 **WASD** 이동 / **Z** 되돌리기 / **R** 다시 / 모바일은 스와이프·D패드
- 목표: **빛(밝은 칸)은 벽과 같다.** 그림자 칸으로만 이동해 출구 ⊙ 에 도달.

## 핵심 규칙

| 요소 | 동작 |
|---|---|
| 빛 | 플레이어가 밟을 수 없음(벽과 동일). 상자·벽은 빛을 가로막아 그림자를 만든다. |
| 상자 | 소코반처럼 밀 수 있음. 빛을 가려 **그림자 길**을 연다. 밀어낸 칸이 여전히 밝으면 따라 들어가지 않고 제자리에 머문다. |
| 깜빡이는 등불 | 주기적으로 켜졌다 꺼짐. 어둠의 순간을 노려 통과. 빛에 닿으면 시작 지점으로 되돌아감. |
| **압력판 스위치** | 상자를 밀어 올려놓으면 **연결된 등불이 꺼진다.** 빛의 벽을 끄는 열쇠. |

## 레벨 구성 (튜토리얼 → 심화, 총 10)

1. **첫 그림자** — 빛을 피해 그림자로 걷기
2. **등불 사이** — 두 빛 사이 틈으로 통과
3. **상자의 그늘** — 상자를 밀어 그림자 길 만들기 *(밀기 필수)*
4. **깜빡임** — 타이밍 맞춰 통과 *(타이밍 필수)*
5. **스위치** — 상자를 스위치에 올려 등불 끄기 *(스위치 필수)*
6. **빛과 스위치** — 한쪽은 끄고, 남은 빛은 그림자로 피하기 *(밀기·스위치 필수)*
7. **빛과 어둠** — 타이밍 + 상자 조합 *(밀기·타이밍 필수)*
8. **빛의 벽** — 상자 두 개로 빛의 벽 허물기 *(밀기 필수)*
9. **엇갈린 빛** — 엇갈려 깜빡이는 두 빛의 벽을 관문마다 타이밍 *(타이밍 필수)*
10. **잔광** — 스위치로 벽을 끄고 마지막 깜빡임을 넘는 피날레 *(밀기·스위치·타이밍 필수)*

## 기술 메모

- 순수 HTML5 + Canvas 2D, 단일 파일, 외부 의존성 0.
- 조명: 각 등불에서 셀 단위 시선(LOS) 판정으로 밝음/그림자를 계산, 부드러운 방사형 글로우로 렌더.
- 모든 레벨은 파이썬 솔버(엔진의 조명 수식을 `Math.round`까지 정확히 미러링)로 **풀이 가능성**, **밀기/스위치/타이밍 필수 여부**를 자동 검증함. (열 수 없는·의미 없는 레벨을 원천 차단)
