# 그림자 서바이벌 · Umbra Survivor

너는 **그림자**. 빛에 닿으면 스러진다. 휩쓰는 빛줄기를 피하고,
어둠 속 **불티**를 모아라. **버틴 시간이 곧 점수** — 무한 서바이벌 아케이드.

> 2026 미니게임 메이커스 챌린지 출품 후보 (기획 B). 움브라(퍼즐)와 같은 빛/그림자 세계관, 장르는 아케이드.

## 플레이 방법

- `B/index.html` 을 브라우저에서 열면 바로 실행. (서버·빌드 불필요, 외부 의존성 0)
- **← ↑ ↓ → / WASD** 이동 · **Space** 대시 · 모바일은 드래그 조이스틱 + 더블탭 대시
- 빛에 닿으면 끝. **기둥 뒤 그림자**에 숨고, **불티**를 모아 콤보 점수를 올려라.

## 중독 설계 (한 판 더)

| 요소 | 내용 |
|---|---|
| 한 판이 짧음 | 보통 30초~2분, 죽으면 즉시 재시작 |
| 점수 경쟁 | 생존시간 + 불티. 최고기록 저장(localStorage) |
| 콤보 | 불티를 연달아 먹으면 배수 x2~x5 (3초 내) |
| 에스컬레이션 | 시간이 갈수록 빛이 늘고 빨라짐 (웨이브) |
| 손맛 | 근접 회피 슬로모·파티클·화면진동·사운드·대시 |
| 대시 | 짧은 무적 순간이동(쿨다운) → 클러치 회피의 숙련 |

## 빛의 종류 (점점 추가)

- **등대 빔** — 축에서 회전하는 부채꼴 빛줄기. 스칠 때를 읽어 피한다.
- **순찰 오브** — 아레나를 튕겨 다니는 점광원.
- (기둥은 빛을 막아 **움직이는 안전 그림자**를 만든다 — 숨을 곳이 계속 바뀐다.)

## 공정성 원칙 (스폰킬 방지)

- 새 등대 빔은 **플레이어 반대쪽을 향해** 생성되어 서서히 다가옴(예고).
- 새 오브는 플레이어에게서 **먼 곳**에 생성.
- 웨이브 등장 시 **0.6초 무적** — 새 빛이 즉사 원인이 될 수 없음.

## 기술 메모 / 검증

- 순수 HTML5 + Canvas 2D, 단일 파일.
- 빛=기하 도형(부채꼴/원) + 기둥에 의한 시선 차단(occlusion)으로 판정. 기둥 뒤 그림자 폴리곤 렌더.
- 헤드리스 시뮬레이션으로 검증: 이동·대시·불티/콤보·충돌 사망·웨이브 에스컬레이션·공정 스폰·재시작 전부 정상, 콘솔 에러 0, 120초 연속 구동 안정.
