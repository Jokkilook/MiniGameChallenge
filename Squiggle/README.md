# 꿈틀꿈틀 · Squiggle

**아무렇게나 생명체를 그려라.** 선 하나든 괴상한 덩어리든 — **살아나서** 뒤뚱뒤뚱
결승선까지 기어간다. 빠를수록 좋은 기록, 망해도 웃기다.

> 2026 미니게임 메이커스 챌린지 / 경기게임오디션 출품 후보.

## 이 게임의 핵심 원칙: "어떤 입력이든 항상 유효하다"

「말하는 대로(단어 소환)」 아이디어의 약점 — *열린 입력을 다 못 받아줌* — 을 정면으로 뒤집었다.
여기선 **어떤 낙서든** 점·스프링으로 바뀌어 **무조건 살아 움직인다.** "못 알아듣는 입력"이 존재하지 않는다.

## 플레이 방법

- `Squiggle/index.html` 을 브라우저에서 열면 바로 실행. (외부 라이브러리 0, 단일 파일)
- 캔버스에 **드래그로 생명체를 그린다** (다리·꼬리·뭐든, 여러 획 OK)
- **살아나라! (Space)** → 물리 시작, 결승선까지 기어간다. **시간 = 점수** (최고기록 저장)
- **지우기** 로 다시 그림 · 달리는 중 **R** 로 재도전

## 왜 재밌나

- **낙서 = 조작** → 남녀노소 즉시, 언어 무관, 못 그려도 오히려 웃김
- **결과 예측불가** → "이번엔 다리를 더 길게…" 실험·최적화 중독 ("한 판 더")
- **1분 영상 최강** → 괴상한 낙서가 버둥대며 완주 = 폭소 + 공유각
- 잘 그린 몸일수록 빠름 → **실력 격차 존재** (스피드런 여지)

## 기술 메모 / 검증

- 순수 HTML5 + Canvas 2D. **mass-spring soft-body 엔진 직접 구현**:
  낙서 → 점(mass) + 스프링, 일부는 **근육**(리듬대로 늘었다 줄었다).
- **이동 원리**: 근육의 *진행파*(위상=초기 x좌표) + **래칫 지면 마찰**
  (뒤로는 꽉 붙잡고 앞으로는 미끄러짐) → 어떤 몸이든 **앞으로 전진**.
- **헤드리스 시뮬레이션 검증**: 지렁이 7초 / 공 17초 / 다리형 19초 / 무작위 낙서 32초 —
  전부 완주, 몸 모양에 따라 속도 차이(실력), 물리 폭주(explode) 없음, 콘솔 에러 0.
