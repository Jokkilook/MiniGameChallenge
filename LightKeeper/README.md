# 빛의 수호자 · Light Keeper

세계관 반전 **타워 디펜스.** A·B에선 빛이 적이었지만, 여기선 **네가 빛 타워를
세워 밀려오는 어둠(그림자 몬스터)을 막는다.** 처치하면 빛이 모이고, 웨이브는 거세진다.

> 2026 미니게임 메이커스 챌린지 / 경기게임오디션 출품 후보 (기획 D). 빛/그림자 4번째 게임.

## 플레이 방법

- `D/index.html` 을 브라우저에서 열면 바로 실행. (단일 파일, 외부 의존성 0)
- 하단 팔레트에서 **타워 선택**(1·2·3 키도 가능) → **길목 옆 빈 칸 클릭**으로 설치
- 설치한 타워 클릭 → **강화 / 판매**
- **다음 웨이브 ▶** (Space) 로 적을 불러온다. 적이 **등불 심장**에 닿으면 생명이 깎임.
- 생명 0 = 패배 / **12 웨이브** 모두 막으면 승리.

## 타워 3종

| 타워 | 빛 | 특성 |
|---|---|---|
| **등불** | 50 | 단일 대상, 균형잡힌 빛살 |
| **섬광** | 110 | 사거리 내 **범위 전체** 타격 |
| **서리빛** | 75 | 적을 **둔화** + 약한 피해 |

- 각 타워 Lv.3까지 강화(피해·사거리·속도 상승). 적을 잡으면 빛(자원)을 얻는다.

## 적 3종 (웨이브로 escalate)

- **정령** — 기본, 다수
- **질주** — 빠름 (3웨이브부터)
- **골렘** — 튼튼, 생명 3 소모 (짝수 웨이브부터)

## 기술 메모 / 검증

- 순수 HTML5 + Canvas 2D. 격자 맵 + 웨이포인트 경로, 자원·강화·웨이브 디렉터.
- **헤드리스 시뮬레이션으로 밸런스 검증**:
  - 타워 없이 방치 → 생명 깎이고 패배(위협 실재).
  - 잘 배치·강화하면 **12웨이브 완막(생명 20 유지, 점수 ~11,700) 승리 가능**.
  - 승리·패배·자원·처치·둔화·범위공격 전부 정상, 콘솔 에러 0.
